- 2026-06-30 — Added [ADR-0009](0009-subject-coach-reflexion-not-on-live-path.md): the ruling on whether to enable the pipeline's **T2 Reflexion** loop for the multi-turn coach. An exploration of the live code established that T2 (`reflect` node, `react_loop.py:3247`) is a **per-task retry within a single run** — it fires on a `failed`/`partial` **GoalJudge** verdict, generates a critique, and re-runs the same task up to 2× (folding the critique into the system prompt) — gated OFF by default with no quality benchmark. Decision: **keep T2 OFF for the coach; reflection lives in the offline judge layer** (the ADR-0008 Pedagogy GoalJudge *is* reflection-on-the-turn). Four independent grounds: (1) **wrong trigger** — a coaching turn has no task-failure verdict to retry (the student's next message is the loop); (2) **counter-pedagogical** — Reflexion converges toward *the correct answer*, the exact answer-leakage behavior the design forbids; (3) **cost** — 2–3 LLM calls/turn on a latency-sensitive chat UX with no measured gain; (4) a **latent bug** — `reflections` (`state.py:144`) uses `_append_list` with **no `task_id` guard**, so on a reused chat `thread_id` a prior turn's critique leaks into the next turn's system prompt (`react_loop.py:2039`). The leak is chat-wide (not coach-only) and is recorded as a **hard prerequisite** for ever enabling T2 in conversation, flagged as a **separate fix task** (add a `reflections_task_id` guard mirroring `planning_depth_task_id`). General principle stated: inline Reflexion is for **checkable single-task runs**, not conversational turns. Grounded in 2026 reflection trade-off research (skip loops for quick/latency-sensitive replies) + a learning-science study (Feynman teach-back/analogy/gap-surfacing; Oakley focused-diffuse/chunking/active-recall/illusion-of-competence/spaced-repetition — which *validates* the FSRS engine; Holt productive-struggle/autonomy/anti-coercion) — all of which say the coach must *not* rescue the answer, the opposite of Reflexion's purpose. The pedagogy findings also fed back into [the brainstorm](../plan/subject-coach-agent.brainstorm.md) §3.5 and the [spec](../plan/subject-coach-agent.spec.md) (persona teach-back/analogy FR-10/11; two new Pedagogy-judge axes — productive-struggle preservation + illusion-of-competence — FR-15).
