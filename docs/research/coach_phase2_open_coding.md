## 1. Method + provenance

- **Unit:** one coach turn (learner utterance → coach reply), drawn from the
  merged batch-2 + batch-2b synthetic shadow corpus via the posture filter
  (`coding_eligible` + `partial_context`; confounds dropped).
- **Sampling:** `build_coach_open_coding_cases` — full eligible pool, no holdout,
  mode-contiguous, seed 42, capped at 100/mode (200 cards total).
- **Coding:** open coding in the browser coder; codes Enter-committed as chips,
  one memo per borderline call. Codes are short and behavioral (§4 of the
  walkthrough).
- **Verification:** `verify_coded_open_codes` → `OK — 200 rows, all have
  open_codes` (no empty-`open_codes` row). Inventory regenerated by
  `build_coach_open_code_inventory`.

**Dataset totals (reconciled against `coded.jsonl`):** 200 rows · **27 distinct
codes** · **496 code instances** · **45 rows carry a DUP-FLAG (22.5%)** ·
`truncated-reply` = **34 (17%)** *(code count authoritative; the running memo
counter ended at 33 — one early truncation coded before numbering began).*
