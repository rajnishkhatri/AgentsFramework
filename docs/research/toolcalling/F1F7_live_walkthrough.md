- **Trace reasoning** — the model→tool→error→completion trajectory rebuilt from BlackBox carriers; `error_class=…` is the taxonomy field the fixes added. `▼ turn N begins` marks a new `task_started` (multi-turn).
- **Carrier verdict** — the positive carrier(s) asserted + negative controls.
- **Langfuse trace** — clickable span view (cost/latency).  **Screenshot** — the Playwright full-page capture.

### Interpreting PASS / SKIP
- **PASS** — the fix's carrier fired on the live trace and the pre-fix failure was absent. The headline is **F1**: the boundary-violating path now stamps `error_class=validation` (pre-fix it was masked as a plain `Error:` string with no class).

- **F7 nuance** — the fix is that **turn 2 reaches the model with no GLM provider rejection**; the trajectory shows `▼ turn 2 begins` + a model selection with zero `llm_call` errors, which is the proof. (The captured answer is turn 1's; GLM's empty-output on turn 2 yields no further tools.)
