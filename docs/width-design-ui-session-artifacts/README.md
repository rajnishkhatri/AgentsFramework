# Session artifacts — Wide-Layout & Coach-Panel Parity

Design + spec deliverables for the PreACT English Coach `/learn/*` wide-layout parity pass.

## Contents
1. **English Coach - Wide Layout UX Decision.dc.html** — the UX Decision Record (editable source).
   Decision log A1–F3, 4 wireframes, component inventory, state model, EARS acceptance criteria,
   risks, non-goals. Theme + FR-ref toggles.
2. **English Coach - Wide Layout UX Decision (standalone).html** — the same doc, self-contained;
   opens offline in any browser, no server.
3. **PreACT-English-Coach-v2-Wide-Layout-CoachPanel-Implementation-Spec.md** — coding-agent SDD spec:
   `isWide` seam, file-by-file change plan, height-chain contract, new components
   (CollapsibleCoachAnswer, use_collapsible_thread, shell_layout_store), state model, 15 EARS
   criteria, open risks, test plan, non-goals.

## Reading order
Decision Record (the "why") → Implementation Spec (the "how"). The standalone HTML is for sharing.
